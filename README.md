# Catat Ceramah

Aplikasi web untuk mencatat ceramah/kajian. Rekam suara ustadz (Google Chrome), dan ayat Al-Qur'an atau hadits yang disebut langsung bisa disisipkan lengkap dengan teks Arab dan terjemah bahasa Indonesia.

- Al-Qur'an 114 surat: teks Arab, latin, terjemah Indonesia (dari paket npm `quran-json`).
- Hadits 9 imam berbahasa Indonesia (dari `gadingnst/hadith-api`) dan Arba'in Nawawi (paket npm `arbain-id`).
- Catatan tersimpan di browser masing-masing (localStorage), tidak dikirim ke server mana pun.
- Bisa dipasang ke layar utama HP dan dibuka tanpa sinyal setelah pertama kali dibuka.
